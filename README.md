HALLOWEEN BABY — MODELO INTERATIVO

Esta versão replica a mecânica do site de referência:
- matriz 3×3;
- nove espaços prateados raspáveis;
- dedo, mouse e caneta;
- é possível arrastar por vários quadrinhos;
- quando aproximadamente 50% de uma casa é raspada, ela abre sozinha;
- só há revelação quando uma linha, coluna ou diagonal válida se completa;
- a seção final fica completamente escondida antes disso;
- botão para raspar novamente;
- resultado fixo, não aleatório.

Para publicar:
1. envie index.html para um repositório GitHub;
2. ative GitHub Pages;
ou use Netlify/Vercel.

O arquivo é autônomo: as imagens estão embutidas no próprio HTML.
